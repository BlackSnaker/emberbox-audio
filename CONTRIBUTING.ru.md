# Участие в разработке

[English](CONTRIBUTING.md) · **Русский**

Приветствуются небольшие, понятные улучшения. В отчёте об ошибке полезны дистрибутив, рабочее окружение/композитор, X11 или Wayland, версия Python и версии соответствующих плееров. Для рекомендаций Spotify укажи также версию клиента. Личные данные и закрытые журналы публиковать не нужно.

## Проверки

```sh
python3 -m compileall -q src tools tests
python3 -m unittest discover -s tests -p 'test_*.py' -v
GDK_BACKEND=x11 dbus-run-session -- xvfb-run -a python3 tests/gui_smoke.py
```

GUI-проверка использует изолированные каталоги XDG и демонстрационные метаданные. Она не управляет настоящим Spotify и звуком рабочего стола. Для проверки настоящего воспроизведения нужен сеанс рабочего стола и PipeWire.

Пересоздание превью:

```sh
GDK_BACKEND=x11 dbus-run-session -- xvfb-run -a python3 tools/render_preview.py --output /tmp/emberbox-preview
```

При изменении оформления сохраняй [принципы Грунесфизма](docs/DESIGN.ru.md), читаемость и расстояния между кнопками мини-режима. Полный экран проверяй по размеру самого видео, а не только по размеру верхнего окна.
