Apple Music внутри Emberbox

Модуль передаёт из уже открытой вкладки Apple Music названия, обложки, альбомы, плейлисты и команды воспроизведения в локальный виджет. Доступ ограничен music.apple.com. Cookies, пароли и токены не копируются. Сторонним серверам данные не отправляются.

  1. Для установки из исходников сначала выполни python3 tools/apple_browser.py install. В настроенной локальной версии этот шаг уже выполнен.
  2. Открой в Firefox about:debugging#/runtime/this-firefox.
  3. Нажми «Загрузить временное дополнение…» / Load Temporary Add-on….
  4. Выбери manifest.json из этой папки: browser/apple-music.
  5. Оставь вкладку Apple Music открытой. В Emberbox открой «Медиатека» и нажми ↻.

Это неподписанная версия для разработки. Firefox удаляет временные дополнения после перезапуска. Для постоянной установки потребуется подпись Mozilla; проверки подписей отключать не нужно.

English

Register the native host with python3 tools/apple_browser.py install. Open about:debugging#/runtime/this-firefox, choose Load Temporary Add-on, select this folder’s manifest.json, then refresh the library inside Emberbox. Only music.apple.com is accessed; credentials stay in the browser. Temporary add-ons last until Firefox restarts. A signed Mozilla distribution is required for persistent installation.
