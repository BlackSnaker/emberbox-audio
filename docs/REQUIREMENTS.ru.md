# Системные требования

[English](REQUIREMENTS.md) · **Русский**

Emberbox Audio — настольное приложение для Linux. Обычное прослушивание,
полноэкранные обложки и локальное AI-караоке требуют разных ресурсов.

## Коротко об оборудовании

**Это предварительные рекомендации по ресурсам, а не подтверждённый тестами
аппаратный минимум.** Самую слабую рабочую конфигурацию CPU и памяти мы ещё
не определили. Объём RAM указан для всей системы, включая рабочий стол
и музыкальный источник.

| Ресурс | Музыка, лампы и полный экран | Локальное AI-приглушение вокала |
| --- | --- | --- |
| Ориентир по CPU | 2 современных ядра | 4 современных ядра / 8 потоков; тест перед запуском должен успевать за звуком |
| Ориентир по RAM | 4 ГБ | От 8 ГБ; на проверенном компьютере разработчика — 16 ГБ |
| Запас свободного места | Предусмотреть 1 ГБ | Предусмотреть 2 ГБ суммарно, вместе с плеером |
| Графика | Встроенная; для анимированных обложек и переходов рекомендуется аппаратный OpenGL 3.2 | Те же требования к отображению; AI работает на CPU, без CUDA и дискретной видеокарты |
| Экран | Самая маленькая проверенная полноэкранная компоновка: 1024×600 логических пикселей | Та же; на большем экране просторнее текст песни |

На плавность влияют поколение процессора, ограничения питания, другие
приложения и выбранный движок воспроизведения. Одно количество ядер не
гарантирует AI в реальном времени. Цифры свободного места — запас для
планирования, а не фиксированный размер установки: дополнительные пакеты
дистрибутива, Spotify или браузер, профили аккаунтов и растущий кэш могут
потребовать больше. При масштабе экрана выше 100% физических пикселей должно
хватать для проверенной логической рабочей области.

## Обязательные программные компоненты

| Компонент | Требование |
| --- | --- |
| Платформа | Linux; **текущая проверенная архитектура — x86_64**. Встроенный DRM для Apple/Яндекса ожидает Widevine для Linux x64. ARM не проверен. Windows и macOS не поддерживаются. |
| Графический сеанс | X11 либо Wayland **с XWayland**; в обоих случаях GTK использует бэкенд X11 |
| Звук | Работающий PipeWire, утилиты `pw-record`, `pw-play`, `pw-link`, `pw-dump`, а также `pactl` и `pacat`. Для караоке дополнительно нужен совместимый сервер протокола PulseAudio, обычно PipeWire-Pulse, с поддержкой null-sink. |
| Python и интерфейс | Python ≥ 3.10, PyGObject, GTK 3, GdkX11 и загрузчик изображений SVG |
| Библиотеки Python | NumPy ≥ 1.24, Pillow ≥ 10 и websocket-client ≥ 1.6 |
| YouTube | libmpv, python-mpv, yt-dlp с совместимыми скриптами EJS и Deno ≥ 2.3 либо Node ≥ 22 |
| Видеообложки | FFmpeg; стандартный установщик проверяет его наличие. Без анимации остаются статичные обложки. |
| Сеть | Интернет для установки и загрузок, стриминга, сетевых обложек и автотекста; подготовка AI дополнительно скачивает модель и среду |

Для описанной установки через `git clone` нужен Git. Пользовательский менеджер
служб systemd необязателен: запускатель умеет запускать приложение напрямую.

Установщик проверяет имеющиеся компоненты и готовит недостающие зависимости
в **Arch и совместимых производных, Debian/Ubuntu, Fedora и openSUSE**.
Доступность пакетов зависит от версии дистрибутива и подключённых репозиториев.
На неизвестных и неизменяемых системах зависимости нужно предоставить штатными
средствами их пакетной системы. [Подробности установки и поддержки дистрибутивов →](INSTALL.ru.md)

## Музыкальные источники

| Источник | Что нужно дополнительно |
| --- | --- |
| Spotify | Аккаунт Spotify и совместимый установленный Chromium/Widevine-движок для встроенного сеанса. Настольный клиент необязателен. |
| Apple Music | Подписка Apple Music и совместимый установленный движок Electron/Chromium с рабочими AAC/EME и Widevine для Linux x64. Настройка проверяет возможности движка; вход остаётся на сайте Apple. |
| YouTube | Перечисленные выше зависимости YouTube. Для публично доступного воспроизведения аккаунт обычно не нужен. |
| Яндекс Музыка | Яндекс ID, Яндекс Плюс и совместимый движок воспроизведения/DRM. Воспроизведение с подпиской остаётся экспериментальным и ожидает проверки тестерами. |

Emberbox не поставляет проприетарные DRM-библиотеки и не устанавливает Spotify.
Установка GTK-плеера сама по себе не оформляет подписку и не подключает все
источники. [Подключение аккаунтов →](ACCOUNTS.ru.md)

## EmberFlow и подгонка битов

Дополнительная модель не нужна. На время перехода готовится один дополнительный
проигрыватель; Apple добавляет рендерер MusicKit и небольшой Web Audio граф.
YouTube использует уже проверяемый установщиком FFmpeg: один поток с пониженным
приоритетом анализирует до 6,5 секунды аудио. Наблюдения хранятся только в памяти,
обычный звук воспроизводит исходный движок. Анализ текущего YouTube-трека работает
в потоке ламп, оценка BPM обновляется не чаще раза в секунду. При отключённых
«Битах» этот анализ и предварительное декодирование прекращаются.

## Необязательный Apple Music Atmos

Для пространственного режима нужны **Linux x86_64, glibc ≥ 2.34**, совместимый
Widevine и C++17-компилятор. `./install.sh --apple-atmos` проверяет компоненты
и готовит декодер; архив около 100 МБ, предусмотрите ещё 250 МБ свободного места.
Звук — 48 кГц для наушников. EmberFlow временно включает второй декодер; буферы
ограничены четырьмя секундами на вход микшера плюс транспортные буферы.
Дополнительная нейросеть не нужна. Минимальный CPU для этого режима ещё не определён;
проверка обычной установки не гарантирует пространственный рендер в реальном времени.
[Подробности и ограничения бета-версии →](ATMOS_PROTOTYPE.ru.md)

Для коррекции наушников используется **SciPy ≥1.10** с готовыми нативными
фильтрами. Нативная установка и обновление уже подготовленного движка проверяют
эту зависимость. Дополнительная нейросеть не нужна; общий EQ после EmberFlow
не создаёт второго декодера. Упреждение защиты пиков — 5 мс.
Личные SOFA-файлы ограничены 32 МБ и проверяются отдельно, до выбора.
[Настройка звука наушников →](HEADPHONES.ru.md)

## Дополнительные ресурсы для AI-караоке

- При первом использовании скачивается **модель UVR размером 30 МБ** с проверкой
  SHA256 и готовится личное окружение ONNX Runtime / ONNX / SciPy. Зависимости
  добавляют примерно **100–250 МБ**, в зависимости от повторно используемых
  пакетов; для подготовки и обновления нужно и временное место. Эти файлы
  добавляются к движку источника и его кэшу.
- Обработка идёт локально на CPU, **до четырёх потоков вычисления**. GPU,
  CUDA, ключ API и дополнительный аккаунт не требуются.
- Тест перед включением выбирает размер блока обработки. Если вычисления не
  успевают или буфер выходит за пределы, эффект останавливается и возвращается
  исходный звук. Одна проверка зависимостей не определяет производительность AI.
- **Быстро · стерео** — явно выбираемый облегчённый вариант без загрузки модели.
  Караоке с одним текстом также работает без подготовки AI.

## Что действительно проверено

Ориентир разработки v0.11.3 — **AMD Custom APU 0405, 4 ядра / 8 потоков,
16 ГБ RAM и встроенная графика AMD**, Linux x86_64. Локальная UVR с антишумом
на этом компьютере требует около **2–3 секунд буферизации**; плеер показывает
измеренную задержку. Это результат на конкретной конфигурации, а не минимальные
требования или обещание такой же задержки на других компьютерах.

- **GNOME 50, Wayland + XWayland:** исходное рабочее окружение.
- **KWin 6.7.5, вложенный Wayland + XWayland:** проверены размещение окна, ввод,
  прозрачные скругления и возврат из полного экрана. Полноценный сеанс Plasma
  Shell ещё требует [проверки тестерами KDE](KDE.ru.md).
- **1024×600, 1280×720 и 1920×1080:** проверена полноэкранная компоновка,
  включая управление караоке. Проверка компоновки не определяет частоту кадров
  на каждой видеокарте.

Из папки проекта можно проверить программные компоненты без установки:

```sh
./install.sh --check --lang ru --plain
```

Команда проверяет зависимости, а не доступную RAM, запас места, права аккаунта
или скорость AI в реальном времени. Для отчёта об оборудовании укажите модель
CPU, RAM, дистрибутив, рабочий стол и сеанс, масштаб экрана, источник и режим,
в котором возникает проблема.

## Локальный Ember DJ

Отдельная необязательная функция: ориентир 4 современных ядра, 8 ГБ RAM для системы
и ещё 3 ГБ свободного места под модели и среду. Текстовый подбор по настроению
работает без моделей; голос и языковой ИИ подготавливаются во вкладке DJ.
[Подключение, проверенные компоненты и ограничения →](DJ.ru.md)

## Необязательный Apple Lossless / Hi-Res

`./install.sh --apple-lossless` также готовит нативный ALAC-адаптер и проверяет GCC/G++, make, git, OpenSSL и libcurl. Дополнительная загрузка — около 75 МБ сверх OpenJOC. Для подготовки и обновлений предусмотрите суммарно около 500 МБ свободного места и 512 МБ дополнительного запаса RAM на нативный тракт и перекрытие треков. Это запас ресурсов, а не измеренный минимум оборудования. Android-виртуальная машина и новая нейросеть не запускаются. Отдельный вход в Apple доступен из настроек плеера. Для EmberFlow с разными форматами используется общий микшер 192 кГц. [Подробности →](ATMOS_PROTOTYPE.ru.md)
