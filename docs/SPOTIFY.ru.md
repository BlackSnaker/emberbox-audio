# Подключение Spotify

[English](SPOTIFY.md) · **Русский**

## Вход из плеера

Открой **Настройки → Аккаунты → Войти в Spotify**, заверши официальный вход в клиенте и включи трек. Статус обновится автоматически. Если клиента нет, кнопка установки откроет официальную страницу загрузки. [Подключение аккаунтов](ACCOUNTS.ru.md).

## Основное управление

Открой настольный Spotify. Emberbox получает информацию о треке и управляет воспроизведением и перемоткой через MPRIS. Крутилка и тумблер действуют на аудиопоток Spotify, а не на общую громкость системы.

Поддерживается запуск обычного `spotify` и Flatpak `com.spotify.Client`. Звук Flatpak должен быть доступен в PipeWire хоста.

## Личные подборки — по желанию

Панель **For you** показывает личные коллекции Spotify и их треки. Открой **Настройки → Аккаунты → Подключить личные подборки**, чтобы включить локальное подключение. Это может один раз перезапустить Spotify и прервать воспроизведение.

Ранняя версия интеграции соединяется с отладочным интерфейсом Chromium внутри настольного Spotify по адресу **127.0.0.1:43827**. Она читает музыкальные метаданные из интерфейса клиента и вызывает его локальный плеер. Это не Spotify Web API; ключ разработчика и отдельный OAuth-вход не нужны. Обновление клиента может изменить внутренние интерфейсы и потребовать исправления интеграции.

Этот интерфейс даёт другим локальным программам отладочный доступ к клиенту. Emberbox открывает его на loopback; порт не следует публиковать или перенаправлять наружу. Если такое подключение не нужно, можно пользоваться основным управлением без панели подборок.

Emberbox не читает cookies, пароли и токены сеанса. Метаданные коллекций и миниатюры сохраняются в локальном XDG-кеше. Удалённого сервиса Emberbox нет.

Загрузка подборок может переключать страницу внутри Spotify. Нажатие на трек в виджете предназначено для фонового воспроизведения без поднятия окна Spotify.
