# KDE Plasma / KWin

[English](KDE.md) · **Русский**

Emberbox сохраняет [материалы Грунесфизма](DESIGN.ru.md) в KDE: прозрачные скруглённые углы, мягкий объём, читаемые кнопки и тёплый свет. Используй обычный [установщик](INSTALL.ru.md): отдельная сборка или тема для KDE не нужна. В сеансе Wayland требуется XWayland.

## Что проверено

В Plasma установщик добавляет Emberbox в меню приложений и автоматически создаёт ярлык в настроенной папке рабочего стола. У ярлыка есть действия «Показать», «Скрыть» и «Закрыть». Отключить его можно через `./install.sh --no-desktop-shortcut`; обновления запоминают этот выбор. Закрепление в панели доступно через меню приложений Plasma. [Параметры установки](INSTALL.ru.md).

Интеграционный тест выполнен на **KWin 6.7.5 во вложенном сеансе Wayland с XWayland**, поверх Xvfb, с композитингом QPainter. Он проверяет настоящий композитор и события мыши и клавиатуры. Это контролируемое тестовое окружение; полноценный рабочий стол Plasma Shell в него не входит.

| Проверка | Результат в этом сеансе |
| --- | --- |
| Прозрачные скругления | На итоговом изображении угловой пиксель показывал искусственный фон рабочего стола, а поверхность карточки оставалась непрозрачной. |
| Слой рабочего стола | Виджет работал обычным окном под приложениями, с постоянным идентификатором, без записи в панели задач и переключателе рабочих столов. |
| Фокус при запуске | Появление виджета не забирало фокус клавиатуры. |
| Мышь и клавиатура | Настройки открывались нажатием мыши, поле поиска принимало ввод. |
| Перетаскивание | Перетаскивание за обложку перемещало окно средствами KWin. |
| Виртуальные рабочие столы | Узко ограниченный временный скрипт KWin размещал только настольный виджет на всех рабочих столах. |
| Полный экран | Комната прослушивания получала фокус и более высокий слой. Она не оставалась под приложениями или на всех рабочих столах. Esc возвращал положение, размер и компактное состояние виджета. |

Эти результаты **не подтверждают** полноценный сеанс Plasma Shell, родной KWin X11, KDE 6.8, аппаратные графические драйверы или физическую конфигурацию из нескольких мониторов. Расчёт рабочей области с панелями и несколькими экранами дополнительно проверен на искусственной геометрии; настоящие панели должны проверить тестеры. Доступ к музыкальным аккаунтам проверяется отдельно от оконного менеджера.

## Как размещается виджет

Emberbox определяет KDE/Plasma по окружению рабочего стола либо имени оконного менеджера KWin. В KDE выбирается обычное окно под приложениями: так сохраняются прозрачность и работа органов управления. В других окружениях остаётся исходный режим настольного окна. Полноэкранная комната прослушивания открывается отдельным обычным полноэкранным окном.

Для размещения на виртуальных рабочих столах KWin/XWayland используется временный скрипт только для **resource name `emberbox-audio` и роли окна `desktop-widget`**. Он не меняет общие настройки KWin и не устанавливает постоянные правила окон. Если скрипты недоступны, виджет продолжает работать, но может оставаться на текущем рабочем столе.

Типы и свойства окон описаны в [реализации окон X11](https://github.com/KDE/kwin/blob/master/src/x11window.cpp), [общей реализации окон](https://github.com/KDE/kwin/blob/master/src/window.cpp) и [API скриптов KWin](https://develop.kde.org/docs/plasma/kwin/api/). Также доступно описание [архитектуры Wayland в KDE](https://community.kde.org/KWin/Wayland).

## Если окно размещается неправильно

### Явно выбрать режим

`EMBERBOX_DESKTOP_MODE` переопределяет автоматический выбор:

| Значение | Поведение |
| --- | --- |
| `normal` | Обычное окно под приложениями; режим по умолчанию в KDE. |
| `desktop` | Настольное окно; исходный режим для других окружений. |

Перед проверкой останови уже запущенную копию. Из каталога исходников:

```sh
# Если установленная копия использует пользовательскую службу:
systemctl --user stop emberbox-audio.service
# Проверка одного режима:
EMBERBOX_DESKTOP_MODE=normal ./run.sh
```

Для сравнения замени `normal` на `desktop`. Чтобы сохранить выбор для установленной службы systemd, выполни `systemctl --user edit emberbox-audio.service` и добавь:

```ini
[Service]
Environment=EMBERBOX_DESKTOP_MODE=normal
```

После этого перезапусти службу. Настройка действует только на Emberbox.

### Если скрипт всех рабочих столов недоступен

Можно оставить виджет на текущем рабочем столе либо создать **пользовательское правило окна** в **Параметры системы → Управление окнами → Правила окон**. Укажи одновременно класс окна Emberbox (`emberbox-audio` / `EmberboxAudio` — смотри результат определения свойств окна) и точную роль **`desktop-widget`**. Выбери размещение на **всех рабочих столах**; название свойства зависит от версии Plasma.

Ограничение по роли оставляет комнату прослушивания и окна входа вне этого правила. Если редактор правил не умеет сопоставлять роль, оставь виджет на текущем рабочем столе вместо правила для всего приложения. Менять общие настройки KWin не требуется.

## Список проверок для тестеров Plasma

Проверь в своём настоящем сеансе:

- Запуск из меню и при входе: должен появляться один виджет.
- Мини-режим, меню, поиск, перетаскивание и сохранение положения при выбранном масштабе.
- Размещение под приложениями, команду **«Показать рабочий стол»**, виртуальные рабочие столы и комнаты Activities.
- Полноэкранный режим на каждом мониторе и возвращение по Esc.
- Панели, дробный масштаб, переподключение монитора и сон.
- Звук выбранного источника, громкость, перемотку и живые лампы.

В отчёте укажи дистрибутив, версии Plasma и KWin, X11/Wayland, масштаб, расположение мониторов и панелей, проблемный шаг. Для ошибки установки приложи вывод `./install.sh --check --plain`. Журнал установленной пользовательской службы: `journalctl --user -u emberbox-audio.service -n 40`.
