# Яндекс Музыка · прямой API

[English](YANDEX_MUSIC.md) · **Русский**

Яндекс Музыка работает через API и локальный libmpv, без встроенного сайта, Electron и Widevine. Для полных треков и Моей волны нужны Яндекс Плюс и доступность сервиса в твоём регионе. API не является гарантированным публичным интерфейсом: Яндекс может изменить его.

## Подключение

1. Установи `libmpv`, Python-пакет `python-mpv` и `secret-tool`. Последний входит в `libsecret-tools` на Debian/Ubuntu, `libsecret` на Arch/Fedora, `libsecret-tools` на openSUSE. В рабочем столе должна работать разблокированная служба Secret Service (например, GNOME Keyring или совместимый KWallet).
2. Открой **Настройки → Плеер → Аккаунты и вход → Яндекс Музыка → Войти**. Приложение получит и покажет одноразовый код, а затем откроет `https://ya.ru/device` в браузере. Если браузер не открылся, нажми ссылку в окне или открой адрес вручную.
3. Введи показанный код на сайте Яндекса и подтверди доступ. Пароль и коды подтверждения вводятся только у Яндекса. Приложение автоматически получит токен — искать и копировать его вручную не нужно. Закрытие окна отменяет ожидание; истёкший код можно получить заново, повторив вход.
4. Выбери Яндекс Музыку в источниках. Открой плейлист, найди песню или включи **Мою волну**.

Токен проверяется через `account/status` перед сохранением. Он хранится только в системной связке ключей (`application=emberbox`, `service=yandex-music`), не в JSON, аргументах процесса или браузерном профиле. Если связка недоступна, подключение завершается ошибкой: сохранения открытым текстом нет. Через карточку аккаунта можно заменить токен. Для удаления сохранённого токена используй менеджер связки ключей; для отзыва доступа — настройки аккаунта Яндекса.

## Возможности

- Поиск треков, собственные плейлисты и их треки, локальная очередь.
- Прямое воспроизведение полных MP3-потоков с наибольшим доступным битрейтом, пауза, перемотка, обложки и данные трека. Превью не подменяют полные записи.
- Моя волна через сессии Rotor, автоматическая загрузка следующей порции треков, события начала/завершения и пропуска, лайки и дизлайки.
- Страницы артистов, популярные треки, альбомы и их содержимое. Гостевые релизы это подключение не предоставляет.
- Переключение источника ставит Яндекс на паузу. Медленный запрос ссылки не запускает звук после ухода на другой источник.

Панель Моей волны показывает все полученные строки списка с прокруткой, без обрезки до 50; общая медиатека использует тот же API-клиент. Очередь здесь локальная, а не очередь официального приложения.

## Переход с веб-движка

Старая служба `emberbox-audio-yandex.service` останавливается при запуске нового клиента. Профиль `yandex-web-profile/` и `yandex-engine.json` не удаляются, но больше не используются. Сеансы Apple Music и Spotify не затрагиваются. Старый вход через сайт не превращается в OAuth-токен: токен нужно подключить отдельно.

## Проверка и диагностика

Автоматические тесты проверяют API-контракты на фикстурах, подпись MP3-ссылок, отсутствие токена в медиазапросах, хранение в связке, реакции и блокировку воспроизведения неактивного источника. **Живое воспроизведение с подпиской не проверено в среде разработки.**

С Плюсом проверь восстановление подключения после перезапуска, поиск, плейлисты, Мою волну и её переходы, реакции, перемотку, смену источников и громкость. При ошибке приложи версию приложения, окружение рабочего стола, текст ошибки и действие. Не прикладывай токен, подписанную ссылку на поток или содержимое связки ключей. Истёкший токен нужно заменить в карточке аккаунта.

## Персональные подборки и волна по плейлисту

В разделе Яндекса вкладка **Для тебя** показывает персональные плейлисты, которые API выдаёт твоему аккаунту: например, «Плейлист дня», «Премьера» и другие подборки. Названия и состав берутся у Яндекса, а не задаются в приложении. Если подборка ещё не готова или сервис её не вернул, карточка не выдумывается. Собственные плейлисты остаются во вкладке **Плейлисты**.

Открой любой плейлист и нажми **«Волна по этому плейлисту»**. Это отдельная сессия рекомендаций с плейлистом как исходной точкой, а не простое перемешивание его треков. Верхняя кнопка **«Включить Мою волну»** запускает общую персональную волну.

Текущий режим показан под кнопкой Моей волны: **Моя волна**, **Волна по плейлисту** или **Волна по треку — название**, с состоянием «Играет / Пауза». Этот источник рекомендаций сохраняется при смене треков волны. Кнопка **«Волна по текущему треку»** запускает отдельную волну по песне, которая сейчас выбрана в плеере.

В обычном плейлисте текущая песня выделяется в списке. Кнопка предыдущего трека использует очередь плейлиста; после нескольких секунд воспроизведения первое нажатие возвращает к началу песни. Нажатие **«Далее»** в конце плейлиста запускает волну по нему; простое завершение последней песни само по себе волну не включает. После обновления заново открой плейлист и выбери трек, чтобы в очереди сохранилась привязка к плейлисту.
