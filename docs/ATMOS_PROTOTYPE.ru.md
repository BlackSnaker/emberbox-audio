# Apple Music Atmos: прототип движка

[English](ATMOS_PROTOTYPE.md) · **Русский**

**Состояние на 25 октября 2026: воспроизведение Apple Music Atmos в Emberbox ещё
не включено.** Проверены отдельные звенья. Единый тракт защищённого
воспроизведения не завершён; версия 0.16.3 исправляет отметки каталога.

## Что проверено

| Звено | Результат на машине разработки |
| --- | --- |
| Каталог песни и альбома | Оба передают `audioTraits: atmos`; теперь адаптер распознаёт эту отметку |
| Обычное воспроизведение MusicKit | Декодер сообщает AAC, 44,1 кГц, два канала |
| Авторизованный запрос расширенного HLS | Основной плейлист предлагает `ec-3` с `CHANNELS="16/JOC"` вместе с AAC в сеансе Widevine |
| Текущий Chromium 155 | Проверки MSE и Media Capabilities отклоняют E-AC-3, AC-3 и AC-4; AAC поддерживается |
| Отдельный нативный декодер | OpenJOC 0.20.1 разбирает JOC/OAMD и преобразует открытый тестовый поток в пространственный float32 PCM для наушников, 48 кГц |

Плейлист проверялся внутри авторизованной страницы Apple. Наружу возвращались
только разрешённые обозначения форматов. Ссылки на аудио, токены аккаунта,
ключи, лицензии и аудиосегменты не экспортировались. Наличие дорожки в
плейлисте ещё не подтверждает воспроизведение и JOC-декодирование этой записи.

## Как повторить проверку нативного декодера

[Инструмент для разработчиков](../tools/probe_spatial.py) подаёт локальный файл
небольшими порциями в потоковый C ABI OpenJOC, сразу обрабатывает PCM и получает
хвост фильтра. Он не сохраняет PCM, не открывает аудиоустройство и не обращается
к сети. Установленный плеер его не загружает.

Нужна доверенная библиотека из [релиза OpenJOC 0.20.1](https://github.com/chyinan/OpenJOC/releases/tag/v0.20.1).
Проверен архив `openjoc-0.20.1-x86_64-unknown-linux-gnu.tar.gz`.
Его SHA-256 сверен с контрольными суммами релиза:

```text
a031c473f3036700f66c81337ed73db8734a86b5086989e219e6bd0e1babe72c
```

Открытый тестовый файл проекта —
[`joc.lifecycle.ec3`](https://github.com/chyinan/OpenJOC/blob/v0.20.1/crates/openjoc-wasm/testdata/joc.lifecycle.ec3).
После получения файлов укажите их локальные пути:

```bash
python3 tools/probe_spatial.py \
  --library /полный/путь/к/libopenjoc_capi.so \
  --input /полный/путь/к/joc.lifecycle.ec3
```

Повторный запуск с `--chunk-size 997` проверяет разрезанные входные кадры.
Хеш PCM и количество отсчётов должны совпасть. Инструмент отклоняет поток
без подтверждённого JOC, некорректные числовые значения и неожиданный формат
выхода, ограничивает размер и продолжительность теста.

В одном локальном запуске получено 196 863 кадра с хвостом фильтра: 4,10 секунды
звука за 0,74 секунды обработки. Все отсчёты конечны, пик 0,00331; максимальный
буфер сжатого входа — 4096 байт. Короткий синтетический тест не гарантирует
такую скорость на коммерческих альбомах и других профилях JOC. В JSON явно
указано `appleMusicPlaybackVerified: false`.

OpenJOC — независимый экспериментальный декодер под Apache-2.0. Его
пространственный рендер не заявляет идентичность рендеру Apple/Dolby или
сертификацию Dolby. [Возможности и ограничения проекта](https://github.com/chyinan/OpenJOC).

## Что ещё нужно сделать в движке

В текущем Electron кодеки встроены в исполняемый файл. Установка FFmpeg или
размещение библиотеки OpenJOC рядом не добавляет E-AC-3 в MSE и не подключает
декодер к защищённому воспроизведению MusicKit.

Нужна поддерживаемая сборка Chromium/Electron с разбором и декодированием
E-AC-3, авторизованным EME/CDM и обработкой JOC/OAMD в том же медиатракте.
Прототип для открытых файлов не обрабатывает зашифрованные HLS-сегменты.
Затем нужны реальные проверки выбора расширенной дорожки, паузы, перемотки,
смены песен, задержки, EmberFlow, караоке и возврата на AAC. Только после
этого можно включать функцию и значок фактически играющего Dolby Atmos.

В Chromium доступ к кодеку управляется
[`enable_platform_ac3_eac3_audio`](https://chromium.googlesource.com/chromium/src/+/main/media/media_options.gni).
Сам флаг не добавляет JOC-рендер. Dolby также разделяет
[выбор дорожки, декодирование и полный пространственный тракт](https://professionalsupport.dolby.com/s/article/Dolby-Audio-and-Dolby-Atmos-in-web-apps?language=en_US).
